EYES OF VICTORY 2027 — Documentation

Monitor. Verify. Respond. Report. — Kano State election monitoring & command centre prototype.

Everything runs with zero npm dependencies: a plain Node.js server plus a hand-built frontend (SVG GIS engine, SVG chart library, no CDNs). The server seeds 44 real Kano LGA boundaries (geoBoundaries), 504 wards, 1,476 polling units and 1,319 field agents, then runs a full simulated election day at 30× real time.

Quick start

node server/server.js → http://localhost:3000. First boot loads the Collation Phase scenario (27 Feb 2027, 16:20 WAT). Switch scenarios from the central header or /admin → Simulation Control.

Public Election Observatory 2.0

The public domain (/public, open access) is a mobile-first national observatory: live status cards with source/status/last-updated, public GIS with LGA→ward→PU monitoring profiles, Result Observatory, public IReV WATCH, What Changed timeline, incident monitor at ward/LGA resolution, Kano Observatory, statistics, published reports, Transparency Centre (methodology, sources, verification, corrections centre, privacy), Media Data Desk with open-data exports and a documented public API (/api/public/*). The public-data principle is absolute: OFFICIAL ELECTION RESULTS vs MONITORING DATA vs IReV OBSERVATIONS vs VERIFIED MONITORING RECORDS are always distinguished, and no "winner" is ever declared from monitoring data.

Result lifecycle

UNVERIFIED → SUBMITTED → UNDER REVIEW → VERIFIED / REJECTED / DISPUTED → ARCHIVED with validation flags (neutral language), anti-duplication (ID, PU, SHA-256, perceptual hash, metadata), versioned corrections (VERSION 1 → VERSION 2 → …), four-eyes approvals and full audit trails.

Architecture notes

  • Real-time — Server-Sent Events broadcast result/incident/SOS/stream/agent events; dashboards update live.
  • Time — stored UTC, displayed Africa/Lagos (WAT).
  • Evidence — immutable originals; SHA-256, custody chain, GPS/device/timestamp metadata.
  • Security — MFA, server-side RBAC on every endpoint, rate limiting, lockout, scrypt password hashing, export audit logging.
  • Scale-out — configurable Country → State → Senatorial → LGA → Ward → PU hierarchy; Kano is deployment #1. Production target: docs/schema.sql (PostgreSQL + PostGIS).

Responsible election technology

No voter profiling or persuasion. Monitoring data is never presented as official INEC results. The intelligence engine separates RAW / VERIFIED / DERIVED / ANALYTICAL / HUMAN data categories. Every record preserves SOURCE + TIME + LOCATION + USER + EVIDENCE + STATUS + AUDIT TRAIL. The operational chain is COLLECT → VALIDATE → VERIFY → ANALYZE → ESCALATE → REPORT → ARCHIVE — never collect → assume → publish.
